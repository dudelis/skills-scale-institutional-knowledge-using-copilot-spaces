# OctoAcme — Lifecycle RACI Matrix Template

## Purpose
Use this template to assign clear ownership by lifecycle phase and reduce handoff ambiguity.

## How to use
1. Copy this table into your project doc.
2. Set exactly one **A** (Accountable) per row.
3. Keep **R** (Responsible) to the smallest practical set.
4. Review and update at kickoff, planning, and release readiness.

Legend: **R** = Responsible, **A** = Accountable, **C** = Consulted, **I** = Informed

## Lifecycle RACI Matrix
| Lifecycle Activity | Product Manager | Project Manager | Technical Lead | Developers | QA/Testing | Release Manager | Stakeholders |
|---|---|---|---|---|---|---|---|
| Initiation: problem statement and success metrics | A | C | C | I | I | I | C |
| Initiation: sponsor alignment and go/no-go | C | R | I | I | I | I | A |
| Planning: backlog scope and priority | A | R | C | C | C | I | C |
| Planning: dependency and risk planning | C | A | R | C | C | I | I |
| Execution: implementation and code review flow | I | C | A | R | C | I | I |
| Execution: acceptance and test validation | I | C | C | R | A | I | I |
| Release: readiness gate and deployment decision | C | C | R | R | C | A | I |
| Release: stakeholder release communication | C | R | I | I | I | A | C |
| Retrospective: outcomes and improvement actions | C | A | C | R | R | C | I |
