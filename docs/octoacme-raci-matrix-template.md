# OctoAcme — RACI Matrix Template

## Purpose
Use this template to make ownership explicit for project deliverables, decisions, approvals, and handoffs.

## When to use
- During initiation to confirm who owns approval and setup work
- During planning to remove ambiguity around dependencies and sign-offs
- Before release when multiple teams must approve or communicate the change

## How to use
1. Copy this template into the project repo or planning doc.
2. Keep one **Accountable** owner per row whenever possible.
3. Update the matrix when scope, timelines, or stakeholders change.
4. Review open ownership questions in the weekly PM sync.

## RACI legend
- **R — Responsible:** does the work
- **A — Accountable:** owns the outcome and final decision
- **C — Consulted:** gives input before the decision or handoff
- **I — Informed:** stays updated after the decision or handoff

## Quick review checklist
- [ ] Every major deliverable has one named accountable owner
- [ ] Cross-team dependencies have a clear escalation owner
- [ ] Approvals needed before release are listed
- [ ] Handoffs between Product, Engineering, QA, and Stakeholders are explicit
